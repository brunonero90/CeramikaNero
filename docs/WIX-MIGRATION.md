# Wix Migration

## Current site

The existing website is hosted on Wix at https://www.ceramikanero.com/.

## Migration scope

- Rebuild the public-facing site in Next.js.
- Preserve high-value URLs where possible.
- Migrate static content (text, images, contact details) into the Supabase
  database and Supabase Storage.
- Recreate workshop listings as database-driven content.
- Replace Wix booking forms with custom booking and payment flows (future phase).
- Import existing customer records into `customer_profiles` before they create
  Supabase Auth accounts.
- Preserve original Wix filenames in `media_assets.original_filename`.

## URL redirects

- Redirects are stored in the `legacy_redirects` table.
- Example seed redirects: `/product-page/ceramika-dla-doroslych` → `/warsztaty/ceramika-dla-doroslych`.
- A redirect lookup service is available at `services.redirects.getBySourcePath()`.
- The application will return the configured status code (301 or 308) at runtime.
- Netlify-level redirects can be generated from the database before DNS cutover.

## Images and assets

- Images are exported from Wix and uploaded to Supabase Storage through the admin
  media interface or a secure import process.
- The media picker in workshop, instructor, blog and gallery forms can select
  existing assets or upload new ones with alt text.
- Original Wix filenames are preserved in `media_assets.original_filename`.
- `media_assets.storage_path` is unique and may differ from the original filename.
- Original files are not renamed or optimized destructively; generated responsive
  variants use separate paths and are deferred until the pipeline is ready.
- All image references use Next.js `Image` with width, height and alt text.
- Imported media records use `source = 'wix_import'`.

## Customer data migration

- Wix customer records can be imported into `customer_profiles` with
  `auth_user_id = null`.
- When a customer later creates a Supabase Auth account, `auth_user_id` can be
  populated.
- Imported bookings are stored with `source = 'wix_import'` and `booking_reference`
  generated by the database trigger.
- Newsletter subscriber consent evidence is preserved in the subscriber record.
